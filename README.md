# At2-Radio

Bibliothèque, service local et page de programmation pour la radio **Baofeng / Alervites AT2**, pour construire sa propre application sans refaire la rétro-ingénierie du protocole.

> **Projet communautaire, non affilié à Baofeng ni à Alervites.** Le protocole est issu de la rétro-ingénierie. Tout ce qui n'est pas confirmé sur matériel est marqué comme tel dans `docs/PROTOCOLE.md`.

**État : cadrage.** Aucun code publié pour l'instant. Voir :

- [`docs/CONTRAT.md`](docs/CONTRAT.md) : périmètre, bibliothèque, API, page de programmation, jalons.
- [`docs/INVENTAIRE.md`](docs/INVENTAIRE.md) : fonctions de l'application officielle et écarts à porter.
